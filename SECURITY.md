# Security policy

[简体中文](./SECURITY.zh-CN.md)

## Supported versions

This repository is currently a pre-release format draft. No version is yet
supported for production use.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting for this repository. Do
not open a public issue for suspected credentials, private data exposure, or a
security weakness.

Reports should include the affected file or version, expected impact, and the
smallest safe reproduction. Do not include real credentials or personal data.
