# 公开来源政策

[English](./public-source-policy.md)

本仓库只使用公众能够独立检查的信息和制品。

## 可以收录

- 具有稳定地址和明确版本的公开文档；
- 公开源码仓库与不可变 Release 标识；
- 使用保留示例域名的明确虚构示例；
- 不复刻保密工作的原创社区文档。

## 不得收录

- 凭据、会话数据、私有地址、个人本机路径或私有仓库坐标；
- 只能从私有计划获知的源码、规范、包名、截图或兼容性证据；
- 被包装成正式版本的可变分支引用；
- 缺少公开证据的上游背书、官方身份、安全或兼容性声明；
- 整合包定义中的安装 Hook 或任意命令。

## 证据规则

公开证据不完整时，仓库必须把相应事实标记为未知。不得使用私有测试结果填补公开证据空白。
